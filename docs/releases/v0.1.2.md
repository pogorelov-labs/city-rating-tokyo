# v0.1.2 — Map interaction and score consistency

Draft release notes; v0.1.2 has not yet been published.

## Fixes

- The Bangkok grid panel now applies the flood-risk filter to its count and
  ranked hotspots, keeping them aligned with the map.
- Tokyo map selections can now be cleared with Escape. Hover highlights clear
  consistently across both cities.
- MCP composite scores now round half-values in the same way as the website.

## What to expect

These fixes do not refresh city data. Scores remain relative within each city;
the existing source and confidence limitations still apply.
No database migration or user action is required.

See the [methodology](https://city-rating.pogorelov.dev/methodology) for data
limits and the [changelog](https://github.com/pogorelov-labs/city-rating-tokyo/blob/main/CHANGELOG.md)
for version history.
