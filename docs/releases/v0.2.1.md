# v0.2.1 — City preferences and seismic labels

Released 2026-10-31.

This patch fixes two issues identified while verifying v0.2.0.

## Preferences follow you between cities

Custom score weights now travel with city-switch links, including full page
navigation and opening a link in a new tab. City-specific rent and commute
filters, selected areas and comparisons stay separate. Language selection is
retained in English, Japanese and Russian.

## Seismic labels match their source

Tokyo's seismic labels and legends now use the probability bands in the data
source: below 3%, 3% to under 6%, 6% to under 26%, and 26% or higher. For
example, an 8.88% probability is labeled High. The previous display labeled it
Moderate. Percentages show up to two decimal places so a stored value such as
5.97% remains visibly below the next band. Labels use a more readable text color.

The same correction applies in all three languages. The seismic filter caption
now states that its existing cutoff includes 26%.

The source remains [NIED/J-SHIS](https://www.j-shis.bosai.go.jp/). Probabilities
describe the chance of JMA intensity 6-upper or stronger shaking over 30 years;
they are not an earthquake forecast or a building-specific safety assessment.

## Compatibility and data limits

Existing links and ranking formulas remain compatible. Source probabilities,
datasets and filter behavior are unchanged; this release does not refresh data.
The rent, commute and evidence-coverage limits described in
[v0.2.0](v0.2.0.md) still apply.

No database migration or user action is required.
