  нет — page extraction не настроен) — файл сохранён как есть.

## 3. 港区商店街 GeoJSON — ✅ acquired через веб-архив (живой источник удалён/закрыт)

Попытки по возрастанию, каждая зафиксирована:
1. Прямой curl download-URL (браузерный UA + Referer TMG-каталога) → **403**
   (HTML-заглушка «エラー 403», CKAN 2.11.5, `_csrf_token` в meta).
2. Cookie-flow (GET / с cookie-jar → 200, потом download с cookies) → **403**.
3. API-вариант каталога (подсказка из notes): `/api/3/action/package_search` → 200 OK,
   но набор `minato_shoutengai` в выдаче отсутствует; `/api/3/action/package_show?id=e1b08c99-…`
   → **Authorization Error** («ユーザ にはパッケージ … の閲覧権限がありません»);
   `datastore_search`/`datastore/dump` на ресурс → Authorization Error / 404.
4. Контроль-тест: соседний живой набор (`minatokushisetsujoho_fukugo.json`) качается
   тем же curl без проблем (HTTP 200, application/json) → портал не блокирует
   загрузки массово; семейство «港区観光情報» (商店街/宿泊施設) закрыто приватностью
   или удалено, а метаданные TMG-каталога (пакет t131032d0000000009) устарели.
5. r.jina.ai-прокси → у цели тот же 403 (блок серверный, не отпечаток клиента).
6. Wayback CDX: файл захвачен 2020-10-29 и 2021-01-24 (HTTP 200, application/json,
   одинаковый дайджест), в 2025-10 уже 404 → файл исчез с портала до сегодняшнего дня.
   CSV-вариант в архиве отсутствует (только 404-захваты).
7. **Файл получен**: `web.archive.org/web/20210124001703id_/…` →
   **minato_shoutengai.geojson** (29 753 B, HTTP 200, валидный FeatureCollection,
   54 Point-фичи, свойства: 区分/エリア名称/名称/所在地). Координаты — строками,
   как опубликовал район (не числа).
- Выжимка: **minato-shotengai-summary.json** (54 фичи: 新橋 14, 青山・赤坂 11, 麻布 8,
  白金・高輪 8, 芝・三田 7, 芝浦・港南 4, お台場 2).
- Лицензия CC BY подтверждена архивной страницей набора (「ライセンス: クリエイティブ・コモンズ 表示」)
  и метаданными TMG-каталога. Оговорка: это срез 2020–2021 гг.; в живом портале набора нет.
