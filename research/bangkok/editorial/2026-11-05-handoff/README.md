# Bangkok research handoff package

**Prepared 5 November 2026. Ready as a research brief; not dispatched.**

Give the parallel agent [HANDOFF.md](HANDOFF.md). It contains the scope,
six-place pilot, questions, workflow, storage/review contract, first safe
action and expected return. It can start without this chat history.

- [Priority seed](priority-seed.json): all 183 district/station-area keys,
  default model scores and separate within-cohort ranks. Public popularity is
  explicitly unmeasured. The six-place pilot is a deliberate research order.
- [Source manifest](source-manifest.json): verified sender repository identity,
  dataset digests and weight snapshot. The receiver must qualify its own
  workspace and tools. The sender's dirty application code is not needed to
  research these unchanged tracked datasets.
- [Entity bundle schema](entity-research.schema.json): source/claim/prose
  provenance, geography, dates, question coverage, review and later image rights.
- [Source calibration](SOURCE-CALIBRATION.md): actual current-task web reads
  illustrating enthusiasm versus score, corridor versus catchment, dated
  official material, opaque prices and rejected/inaccessible news sources.
- [Validation result](validation.json): Draft 2020-12 schema meta-validation,
  183 unique keys and six recognized pilot entities. No completed entity
  bundles or independent research approvals are claimed.

The schema describes structure. Approval additionally requires semantic checks:
all twelve unique question IDs, actual app-key/kind consistency, canonical URL
hashes, publisher-family independence, resolved references, claim applicability,
freshness, contradiction handling and evidence-supported editorial copy.
Source URLs must be public HTTP(S) originals, not script/data URLs or news proxies.
No file in this package changes live app data or scoring.
